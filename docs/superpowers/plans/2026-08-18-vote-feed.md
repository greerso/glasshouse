export type VoteType = 'FOR' | 'AGAINST' | 'ABSTAIN' | 'PRESENT' | 'DID_NOT_VOTE';

```ts
// choose.ts
export const SOURCE_RANK: Record<DataSource, number> = {
    decision: 0,
    manual: 1,
    transcript: 2,
    inferred: 3,
};

```

One row per `personId`. Lowest `SOURCE_RANK` wins. Stable sort by `electedOrder` then `personName` using `compareRanks` from `@/lib/sorting/people`.

```ts
// split.ts

```

`isSplit`: if any chosen `voteType` in `{FOR,AGAINST,ABSTAIN}`, split iff more than one distinct type in that set. Else if `result`: `nayCount > 0 || abstainCount > 0`. Else false.

`matchesView`:
- `splits` → `isSplit(...)`
- `named` → `chosen.length > 0`
- `all` → `chosen.length > 0 || result !== null`

}): Promise<{
    voted: VotedSubject[];

        subjectName: string;

Prisma:

- Voted: `subject.findMany` where `cityId`, meeting `dateTime` in `[from, toExclusive)` if set, `released: true` unless `includeUnreleased`, body filter on `councilMeeting.administrativeBodyId`, and `OR: [{ votes: { some: {} } }, { voteResult: { isNot: null } }]`. Map rows into `VotedSubject` / unvoted. Cap: if `voted.length > 2000`, throw a typed `VoteWindowTooLarge` that the page catches and renders the spec message (“narrow from/to”). Do not add a table.

Page algorithm:

1. `getCityCached` → `notFound` if missing.
2. Default body = city’s administrative bodies `find(b => b.type === 'council')?.id ?? 'all'`.
3. `parseVoteFeedParams`.
4. If `bodyId` is not `all` and not in that city’s bodies, treat as default (spec: unknown body id falls back).
5. `civilDayBounds` for from/to when set.
6. `loadVoteFeedData`.
7. On `VoteWindowTooLarge`, render the narrow-dates message.
8. Voted: if `personId` set, keep subjects whose chosen rows include that id. Then `paginateVoted`.
9. Unvoted: drop cancelled meetings and procedural names. Split by `unvotedKind`. Upcoming newest-first, no cap. Awaiting oldest-first, max **5 meetings** (group by meetingId first, then cap meetings, then flatten). Line “N older meetings awaiting minutes” if truncated.
10. Outcome on a card: `result.outcome` if present, else `calculateVoteResult(chosen).passed ? 'PASSED' : 'FAILED'`.
11. Tally: result counts if present, else chosen FOR/AGAINST/ABSTAIN counts. Show abstain slot only if abstain > 0.
12. Named line: chosen votes, `formatSurnameFirst(personName)` + type.
13. Badges: unreviewed if any chosen row or result is unreviewed; inferred if chosen/result source is inferred.
14. Link: `/${cityId}/${meetingId}/subjects/${subjectId}` via `@/i18n/routing` `Link`.
15. Filters: `<Link>` with query string (preserve other params). Never `updateFilterURL`.
16. `tab=agreement` renders `VoteAgreement` instead of the feed list (filters for body/from/to still show).

`Votes` strings (English, all four locales): `title`, `onTheAgenda`, `awaitingMinutes`, `olderAwaiting` (`{count} older meetings awaiting minutes`), `noVotes`, `showAllOutcomes`, `tabFeed`, `tabAgreement`, `viewSplits`, `viewNamed`, `viewAll`, `bodyAll`, `unreviewed`, `inferred`, `passed`, `failed`, `noNamed`, `namedCount`, `unanimousCount`, `splitCount`, `coverageLine` (`{name} named on {n} of {m} items`), `narrowDates`.
